# モリコロ忘れもの受付帳

モリコロパーク（愛・地球博記念公園）のベンチに置かれた「忘れもの」17点を探して、写真で受付していくスタンプ帳です。

**使う：** https://dchemk-sudo.github.io/morikoro/

- 1〜6人で使えます。2人以上のときは、1台のスマホを交代で使って受付します
- 写真と記録は、使う人の端末（ブラウザ）の中にだけ保存されます。サーバーには送りません
- 全部そろったら、または途中でも、写真と記録を1枚の画像にまとめて保存できます
- ページの色は、開いた日の季節（春・夏・秋・冬）で変わります。ページの下の「ページの季節」で固定もできます
- 場所のヒントは、ファンの方が書いた訪問記をもとにした目安です。現地と違うことがあります

非公式のファンメイドです。スタジオジブリ、ジブリパーク、公園の運営とは関係ありません。
